# Yan Xuan — Portfolio Website

**[🔗 View Live Site](https://yan-data04.github.io/Yan_Xuan_Portfolio_Website/)**

A personal portfolio site showcasing my data analytics projects and resume, built
on the Massively template by HTML5 UP.

## Pages

- **Project Page** (`index.html`) — Featured and supporting project cards linking
  to my data analysis and visualisation work, including:
  - Personal Safety in Australia — Data Visualisation (Vega-Lite)
  - Olist E-Commerce Business Analysis (SQL)
  - Australia Drowning Statistics Dashboard (Tableau)
  - MIMIC-III ICU Mortality Prediction (R, Kaggle)
  - COVID-19 Data Cleaning & Visualisation (SQL, Tableau)

- **Resume** (`generic.html`) — Full resume with education, projects, employment
  history, and skills, plus a downloadable PDF version.

## Tech Stack

- HTML5, CSS3
- jQuery
- [Scrollex](https://github.com/ajlkn/jquery.scrollex) — scroll effects
- [Responsive Tools](https://github.com/ajlkn/responsive-tools) — responsive layout
- [Font Awesome](https://fontawesome.io) — icons
- Hosted via GitHub Pages
